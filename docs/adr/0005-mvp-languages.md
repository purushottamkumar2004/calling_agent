# 0005: MVP languages: English and Hindi
Date: 2026-10-22
Status: Accepted

## Context
Pilot callers mostly speak English, Hindi, or a mix.

## Decision
Support English and Hindi, including code-mixed Hinglish. Sarvam for Hindi/Hinglish STT and TTS; Deepgram and ElevenLabs for English.

## Consequences
Language is per-agent config. Adding Kannada, Tamil and others later is a config change plus evaluation scenarios.
